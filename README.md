# AutoLoc

Plateforme de gestion de location de véhicules multi-agences.

## Objectifs du projet
- Gérer le parc de véhicules de plusieurs agences
- Permettre la réservation et la location de véhicules
- Suivre les locations, retours et paiements

## Acteurs
- **Client** : consulte les véhicules disponibles, réserve et loue
- **Agent d'agence** : gère les réservations, remises et retours de véhicules
- **Responsable d'agence** : gère le parc et les agents de son agence
- **Administrateur** : gère les agences, les utilisateurs et la configuration
